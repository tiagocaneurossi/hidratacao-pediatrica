# Hidratação Pediátrica

Calculadora perioperatória pediátrica: hidratação (Holliday-Segar/Furman, Berry, consenso europeu), preparo de glicose 1–2,5% e hemoterapia por peso.

Site estático (sem build), funciona offline e pode ser instalado na tela inicial do celular.

**Ferramenta educacional.** Não substitui o julgamento clínico, o protocolo institucional nem a bula.

Ao publicar uma nova versão, aumente o número em `CACHE` no arquivo `sw.js` para os aparelhos baixarem a atualização.
